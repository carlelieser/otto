# AGENTS.md

## Rules

### Process

- Any justified design choice that addresses a functional or non-functional requirement that is architectually significant must be documented as an ADR. This includes but is not limited to:
    - Structure (for example, patterns such as microservices)
    - Non-functional requirements (security, high availability, and fault tolerance)
    - Dependencies (coupling of components)
    - Interfaces (APIs and published contracts)
    - Construction techniques (libraries, frameworks, tools, and processes)

### Coding

- Methods must not exceed 10 lines.
- Classes must not exceed 100 lines.
- Use clear names for variables, functions, and classes.

### Git

- Use Conventional Commits.
- Use Conventional Branching.
